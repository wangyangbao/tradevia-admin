# 附录A  编码规则

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》附录 A。原文状态为“需求评审稿（待业务方确认）”，本文件按模块整理，未改变业务规则。

[返回文档总目录](../../README.md)

编码规则一经确定，需在所有系统中保持一致。以下为本系统建议规则，若集团已有强制规范，以集团规范为准，本表随之调整。

**表119  编码规则**

| 对象 | 规则 | 示例 | 说明 |
| --- | --- | --- | --- |
| 业务单元 | BU + 层级码(2) + 流水(3) | BU01001 | 层级码 01 总部、02 事业部、03 大区、04 经销商 |
| 部门 | DP + 业务单元流水(5) + 流水(2) | DP0100101 | 同一业务单元内唯一 |
| 人员 | EM + 业务单元流水(5) + 流水(3) | EM01001001 | 工号，全局唯一 |
| 客户（门店） | CU + 经销商流水(5) + 流水(6) | CU04001000001 | 可读性优先，不使用随机码 |
| 商品 | SKU + 品牌码(2) + 品类码(2) + 流水(4) | SKU01010001 | 与集团物料编码对齐时以集团为准 |
| 仓库 | WH + 经销商流水(5) + 类型(1) + 流水(2) | WH04001101 | 类型 1 中心仓、2 前置仓、3 车仓、4 退货仓 |
| 线路 | RT + 经销商流水(5) + 流水(3) | RT04001001 | 同一经销商内唯一 |
| 销售订单 | SO-经销商流水-YYYYMMDD-流水(4) | SO-04001-20261106-0001 | 按日重置流水，跨日不连续 |
| 发货单 | DN-经销商流水-YYYYMMDD-流水(4) | DN-04001-20261106-0001 | 同上 |
| 出库单 / 入库单 | OB / IB - 仓库编码 - YYYYMMDD - 流水(4) | OB-WH04001101-20261106-0001 | 按仓库按日重置 |
| 调拨单 | TR-调出仓编码-YYYYMMDD-流水(4) | TR-WH04001101-20261106-0001 | 以调出仓为准 |
| 收款单 | RC-经销商流水-YYYYMMDD-流水(4) | RC-04001-20261106-0001 | — |
| 退货单 | SR-经销商流水-YYYYMMDD-流水(4) | SR-04001-20261106-0001 | — |
