# 4.2  我的首页

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》第 4.2 节。原文状态为“需求评审稿（待业务方确认）”，本文件按模块整理，未改变业务规则。

[返回文档总目录](../../README.md)

首页是业务员打开应用后的第一屏，需要在 3 秒内回答三个问题：今天要跑多少家店、还有多少没跑、今天收了多少钱。因此首页只呈现与当日作业直接相关的数据，不做跨周期、跨区域的复杂分析。

**表94  首页区域与数据口径**

| 区域 | 内容 | 数据来源与口径 | 交互 |
| --- | --- | --- | --- |
| 顶部身份条 | 姓名、所属经销商、岗位、在线/离线状态、同步状态图标 | 取人员档案与网络状态 | 点击进入设置页 |
| 今日进度 | 计划拜访门店数、已拜访数、未拜访数、完成率环形图 | 取当日拜访计划与拜访记录，实时计算 | 点击跳转拜访页 |
| 今日收款 | 现金收款、非现金收款、合计；显示与昨日的对比 | 取当日收款单，已确认为准，待确认单独标注 | 点击进入对账页 |
| 客户欠款 | 本人负责门店的应收余额合计、超期金额、超期门店数 | 取应收台账，按业务员维度汇总 | 点击进入欠款清单 |
| 待办事项 | 待审核订单数、被驳回订单数、待交款金额、待处理异常 | 取各业务对象的状态计数 | 逐项跳转到对应页面 |
| 快捷入口 | 扫门店码、快速开单、登记收款、新增门店 | — | 宫格四宫格布局 |
| 业绩速览 | 本月销额、达成率、排名（可选） | 取业绩报表，按日更新 | 点击进入业绩详情 |

首页数据支持下拉刷新，刷新时显示“数据更新于 HH:mm”；离线状态下显示最近一次同步的快照数据，并在顶部以黄色条提示“当前离线，数据为缓存，收款与欠款以联网后为准”。完成率环形图与欠款金额使用统一的视觉规范，红色仅用于超期与异常，避免全屏彩色干扰阅读。
