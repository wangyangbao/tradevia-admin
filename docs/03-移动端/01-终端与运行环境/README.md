# 4.1  终端与运行环境

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》第 4.1 节。原文状态为“需求评审稿（待业务方确认）”，本文件按模块整理，未改变业务规则。

[返回文档总目录](../../README.md)

移动端是业务员与配送员唯一的作业工具，使用场景多为户外、强光、单手操作，且菲律宾部分区域网络信号不稳定。因此移动端的设计前提是“弱网可用、单手可操作、三分钟内完成一次拜访”。任何需要多次跳转或依赖实时网络的设计，都必须重新评估。

**表93  移动端运行环境要求**

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Android 8.0 及以上；iOS 13 及以上。不支持平板专用布局，采用自适应拉伸 |
| 屏幕适配 | 以 375×667 为基准设计，适配 320—480 宽度；关键按钮不小于 44×44 pt，避免误触 |
| 网络 | 支持 4G/5G 与 Wi-Fi；无网络时进入离线模式并明确提示；弱网下自动延长超时并重试 |
| 权限 | 定位（必需，拒绝后无法签到）、相机（必需）、存储（照片缓存）、通知（可选） |
| 登录 | 手机号 + 密码；支持记住账号；连续 5 次失败锁定 30 分钟；支持生物识别快速解锁（可选） |
| 语言 | 简体中文、英文；默认取人员档案的默认语言，可在设置中切换 |
| 版本更新 | 启动时检查版本，强制更新用于修复数据问题，可选更新用于功能迭代；更新包支持增量下载 |
| 设备绑定 | 一个账号默认绑定一台设备，更换设备需管理员解绑，防止账号共用 |
