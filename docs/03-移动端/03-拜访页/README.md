# 4.3  拜访页

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》第 4.3 节。原文状态为“需求评审稿（待业务方确认）”，本文件按模块整理，未改变业务规则。

[返回文档总目录](../../README.md)

拜访页是业务员的核心工作台，以“今日计划”为主线。页面顶部为日期与进度摘要，中部为门店卡片列表，卡片按线路顺序排列，展示门店名称、分类、上次拜访时间、上次订单金额、当前欠款、状态标签。列表默认分为“未拜访”与“已拜访”两个分组，未拜访在前。

**表95  拜访状态定义**

| 拜访状态 | 定义 | 卡片表现 | 可执行操作 |
| --- | --- | --- | --- |
| 计划中 | 已生成计划但未到店 | 灰色标签，显示计划时间 | 签到、导航、跳过（需原因） |
| 已签到 | 已签到但未完成全部动作 | 蓝色标签并显示已完成动作数 | 继续执行动作、开单、离店 |
| 已完成 | 全部必做动作完成并离店 | 绿色标签，显示停留时长与订单金额 | 查看详情、补拍照片（限当日） |
| 已跳过 | 业务员主动跳过或门店关闭 | 橙色标签并显示原因 | 撤销跳过（需管理员权限） |
| 异常 | 异常签到、超时未离店、定位异常 | 红色标签 | 提交异常说明、申请复核 |

**表96  拜访页功能点**

| 功能编号 | 功能点 | 功能描述 | 优先级 |
| --- | --- | --- | --- |
| FR-MOB-01 | 今日计划查看 | 按线路顺序展示当日门店，支持切换日期查看历史与未来计划 | P0 |
| FR-MOB-02 | 到店签到 | 定位校验 + 时间窗校验，成功后可拍照 | P0 |
| FR-MOB-03 | 引导式动作执行 | 按外勤类型顺序逐步引导，展示进度与剩余必做项 | P0 |
| FR-MOB-04 | 拍照与铺货上报 | 调用相机拍摄，自动加水印；铺货按品项勾选 | P0 |
| FR-MOB-05 | 现场开单 | 选品、改量、查看价格与库存，支持离线 | P0 |
| FR-MOB-06 | 登记收款 | 现金/电子钱包/支票，自动计算找零 | P0 |
| FR-MOB-07 | 离店签退 | 校验最短停留与必做动作，记录离店坐标 | P0 |
| FR-MOB-08 | 跳过与异常上报 | 填写原因并选择异常类型，进入管理员待办 | P1 |
| FR-MOB-09 | 门店导航 | 调用地图应用导航至门店坐标 | P1 |
| FR-MOB-10 | 当日补访 | 在线路外临时增加门店拜访，需选择原因 | P1 |

**表97  拜访关键校验**

| 校验项 | 规则 | 失败处理 |
| --- | --- | --- |
| 定位 | 必须获取到精度优于 30 米的坐标 | 提示开启定位或到空旷处重试；连续失败可走异常签到 |
| 距离 | 与门店坐标距离小于规则半径（默认 100 米） | 超出时禁止正常签到，可选择异常签到并拍照 |
| 时间窗 | 在规则允许的时间段内 | 窗口外签到标记“非计划时间”，需填写原因 |
| 必做动作 | 外勤类型中标记必做的动作全部完成 | 未完成时“离店”按钮置灰，列出未完成项 |
| 停留时长 | 不短于规则设置的最短时长 | 过短时提示确认，仍提交则标记“疑似走过场” |
| 重复拜访 | 同一门店当日已有效拜访 | 提示已拜访，仍可执行但标记“重复拜访” |
