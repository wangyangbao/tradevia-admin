# 4.6  对账与交款

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》第 4.6 节。原文状态为“需求评审稿（待业务方确认）”，本文件按模块整理，未改变业务规则。

[返回文档总目录](../../README.md)

对账页面向业务员展示当日的“应交—已交—差异”，是日终必做动作。页面上半部分为汇总卡片，下半部分为明细列表，按订单与收款单逐笔展开。业务员可直接在手机上提交交款，财务在 PC 端确认。

**表101  对账与交款页面结构**

| 区域 | 内容 | 说明 |
| --- | --- | --- |
| 当日汇总 | 订单金额、已收金额、应交现金、已交现金、差异 | 实时计算，差异为正显示“多交”，为负显示“短款” |
| 收款明细 | 按结算方式分组，展示每笔收款的门店、金额、时间 | 点击可查看关联订单 |
| 欠款确认 | 本人负责门店的应收余额与逾期清单 | 支持一键发送催收提醒（短信/推送） |
| 差异登记 | 选择原因、填写说明、上传凭证照片 | 短款必须登记原因，否则不允许提交交款 |
| 提交交款 | 生成交款单，状态为待确认 | 提交后当日收款数据锁定，不可再修改 |
