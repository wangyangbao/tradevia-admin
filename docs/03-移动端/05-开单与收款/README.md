# 4.5  开单与收款

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》第 4.5 节。原文状态为“需求评审稿（待业务方确认）”，本文件按模块整理，未改变业务规则。

[返回文档总目录](../../README.md)

开单页是移动端最复杂的页面，需在有限屏幕内完成选品、改量、查看价格与库存、确认赠品。设计上采用“商品分组 + 购物车”结构：上方按分类与常用商品分组，下方固定购物车栏显示件数与金额，点击展开可调整明细。

为了提升效率，商品列表默认按“本店历史购买”排序，其次按品类顺序；每个商品展示名称、规格、单价与可用库存，缺货商品置灰并提示“库存不足”。数量调整支持“+1 支”“+1 箱”两种步进，切换单位时自动按换算率折算并重算金额。

**表99  开单与收款功能点**

| 功能编号 | 功能点 | 功能描述 | 优先级 |
| --- | --- | --- | --- |
| FR-MOB-18 | 选品与加购 | 按分类/搜索/历史购买选品，支持扫码加入 | P0 |
| FR-MOB-19 | 数量与单位切换 | 箱/支互换，自动折算；超出可用库存时提示 | P0 |
| FR-MOB-20 | 价格展示与特价申请 | 展示实际取价与取价来源；低于最低售价时提交特价申请 | P1 |
| FR-MOB-21 | 赠品选择 | 按买赠规则自动推荐赠品，可手工调整但受比例限制 | P1 |
| FR-MOB-22 | 订单暂存与提交 | 支持保存草稿；提交后生成订单号并展示预计配送日期 | P0 |
| FR-MOB-23 | 收款登记 | 选择方式、录入金额、自动计算找零、生成收款单 | P0 |
| FR-MOB-24 | 电子钱包收款 | 调用 GCash/Maya 收款码，回填支付结果 | P2 |
| FR-MOB-25 | 小票打印 | 蓝牙连接便携打印机，打印订单与收款凭证 | P2 |
| FR-MOB-26 | 订单查看与撤回 | 查看本人订单状态，审核前可撤回修改 | P1 |

**表100  开单与收款场景规则**

| 场景 | 规则 |
| --- | --- |
| 访销开单 | 订单状态为待审核，配送日期默认次日；提交后不可修改，需撤回后重提 |
| 车销开单 | 订单创建即为审核通过并即时扣减车仓库存；现场必须完成收款或选择赊销并校验额度 |
| 现金收款 | 录入实收金额，系统计算找零；实收小于应收时禁止提交，除非选择“部分收款”并填写原因 |
| 赊销 | 仅对已开通账期的客户可选；系统校验剩余额度，超限时禁止并提示联系管理员 |
| 离线开单 | 按本地缓存的可用库存校验；同步时若库存不足，订单标记“库存冲突”转人工处理 |
| 退款 | 移动端不提供退款操作，须由财务在 PC 端发起，避免一线随意退款 |
