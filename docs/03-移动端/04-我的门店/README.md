# 4.4  我的门店

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》第 4.4 节。原文状态为“需求评审稿（待业务方确认）”，本文件按模块整理，未改变业务规则。

[返回文档总目录](../../README.md)

我的门店展示当前业务员负责的全部门店，支持按分类、状态、欠款情况、最近拜访时间筛选，支持按距离由近到远排序。门店卡片展示名称、地址摘要、距离、当前欠款、最近订单日期与状态。点击进入门店详情，详情页包含基础信息、联系人、欠款明细、历史订单、拜访记录、照片墙五个区块。

**表98  我的门店功能点**

| 功能编号 | 功能点 | 功能描述 | 优先级 |
| --- | --- | --- | --- |
| FR-MOB-11 | 门店列表与筛选 | 按分类、状态、欠款、距离筛选与排序 | P0 |
| FR-MOB-12 | 门店详情 | 展示档案、欠款、订单、拜访与照片 | P0 |
| FR-MOB-13 | 新增门店 | 现场采集名称、地址、坐标、门头照、联系人，提交待审核 | P0 |
| FR-MOB-14 | 编辑门店信息 | 允许修改联系人、电话、营业时间、照片；分类与信用额度需管理员 | P1 |
| FR-MOB-15 | 门店导航与电话 | 一键导航、一键拨号 | P1 |
| FR-MOB-16 | 欠款明细查看 | 按订单展示应收、已收、逾期天数 | P1 |
| FR-MOB-17 | 门店二维码 | 生成门店专属二维码，扫码直达门店详情 | P2 |

说明：移动端新增门店时地址采用“省—市—Barangay—街道”四级选择，避免自由文本造成的地址不可用；坐标必须通过地图选点或现场定位采集，不允许手工输入经纬度。
