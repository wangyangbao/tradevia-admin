# 4.7  设置与离线

## 4.7.1  设置项

**表102  设置项清单**

| 设置项 | 内容 | 说明 |
| --- | --- | --- |
| 账号信息 | 姓名、工号、所属经销商、岗位、角色 | 只读，修改需联系管理员 |
| 修改密码 | 原密码 + 新密码 + 确认 | 新密码不少于 8 位，含字母与数字 |
| 语言切换 | 简体中文 / English | 切换后立即生效，单据打印语言同步变化 |
| 消息通知 | 订单审核结果、驳回提醒、交款确认、系统公告 | 可按类型开关；关闭后仍可在待办中查看 |
| 缓存管理 | 显示缓存占用，支持清理图片缓存 | 清理不影响未上传的离线数据 |
| 同步中心 | 待上传数量、上次同步时间、失败列表与重试 | 核心入口，见 4.7.3 |
| 版本更新 | 当前版本、检查更新 | 强制更新时不可跳过 |
| 退出登录 | 清除本地业务数据，保留账号 | 存在未上传数据时提示先上传 |

<a id="section-4-7-2"></a>

## 4.7.2  离线能力范围

离线不是“全部功能都能用”，而是“关键作业不中断”。系统按下表划定离线边界：能在本地完成并缓存的操作允许离线，需要实时校验或涉及资金最终确认的操作禁止离线。

**表103  离线能力矩阵**

| 功能 | 是否支持离线 | 离线时的行为 | 联网后的处理 |
| --- | --- | --- | --- |
| 查看今日拜访计划 | 支持 | 读取本地缓存计划 | 自动增量同步，计划变更以服务端为准 |
| 门店档案查看 | 支持 | 读取缓存的门店信息 | 同步最新字段，冲突以服务端为准 |
| 签到与拍照 | 支持 | 记录设备时间与坐标，照片存本地 | 上传后补写服务端时间，保留“离线提交”标记 |
| 开单 | 支持 | 按缓存库存与价目表开单，生成临时单号 | 上传后分配正式单号；库存冲突转人工 |
| 登记收款 | 支持 | 记录金额与方式，生成待确认收款 | 上传后进入待确认，财务确认后生效 |
| 查看实时库存 | 不支持 | 提示“离线不可用”，展示最近缓存值并标注时间 | — |
| 订单审核 | 不支持 | 按钮置灰并提示需联网 | — |
| 交款提交 | 不支持 | 提示需联网后提交，允许先保存草稿 | — |
| 报表查询 | 不支持 | 展示最近缓存的关键指标 | — |

<a id="section-4-7-3"></a>

## 4.7.3  数据同步机制

同步分为下行与上行两个方向。下行同步在登录、切换账号、下拉刷新、每日首次启动时触发，按“主数据包 + 增量变更”的方式下载，主数据包包含门店、商品、价目表、线路与计划，压缩后控制在 20MB 以内，避免消耗过多流量。上行同步在检测到网络恢复时自动触发，也可由用户在同步中心手动触发。

**表104  离线同步规则**

| 环节 | 规则 |
| --- | --- |
| 自动上传 | 网络恢复后 30 秒内自动上传；Wi-Fi 环境下优先上传照片，移动网络下默认仅上传业务数据，照片待 Wi-Fi |
| 手动上传 | 同步中心提供“立即上传”按钮，展示进度与剩余条数；失败项可单条重试 |
| 幂等 | 每条离线记录携带客户端唯一流水号，服务端按流水号去重，重复上传不产生重复单据 |
| 顺序 | 同一门店的签到、开单、收款按发生顺序上传，避免出现“先收款后开单”的时序错误 |
| 冲突 | 主数据以服务端为准；订单与收款以客户端为准但需通过校验，校验失败标记冲突并进入人工处理队列 |
| 失败处理 | 上传失败保留在本地队列并展示失败原因（网络/校验/权限），不静默丢弃 |
| 数据保留 | 本地数据保留 7 天，超期且已同步的数据自动清理；未同步数据不清理并每日提醒 |
| 安全 | 本地数据库加密存储，退出登录或远程解绑时清除；照片文件按业务类型分目录存放 |

说明：离线数据的核心风险是“设备时间被篡改”。系统在每条记录中同时保存设备时间与首次联网后的服务端时间，二者差异超过 10 分钟的记录标记“时间异常”，进入管理员复核队列。
