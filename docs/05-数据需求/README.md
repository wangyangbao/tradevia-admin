## 6.1  数据分类

系统数据按用途与敏感度分为四类。分类的目的有二：一是确定各类数据的责任人与维护频率，二是确定备份、保留与访问控制的策略。分类不清会导致主数据与业务数据混管，最终无人对准确性负责。

**表111  数据分类**

| 类别 | 包含数据 | 责任方 | 更新频率 | 敏感级别 |
| --- | --- | --- | --- | --- |
| 主数据 | 业务单元、部门、人员、门店、商品、品牌、渠道、单位、币种、仓库、线路 | 总部管理员、经销商管理员 | 低频变更，按需 | 中（含个人信息） |
| 业务数据 | 订单、发货单、出库单、入库单、调拨单、收款单、退货单、盘点单、拜访记录 | 各业务角色 | 高频，实时 | 高（含交易与资金） |
| 分析数据 | 销售汇总、业绩达成、拜访统计、库存周转、应收账龄 | 数据分析员、管理层 | 按日/小时汇总 | 中（脱敏后使用） |
| 日志数据 | 操作日志、接口日志、登录日志、异常日志 | 系统自动 | 实时写入 | 高（含审计证据） |

## 6.2  数据规范

数据规范是保证跨模块数据可关联的前提。以下规范适用于全部主数据与业务单据，开发与实施阶段须逐项落实，验收时按规范抽查。

**表112  数据规范**

| 对象 | 规范 |
| --- | --- |
| 编码 | 统一采用“前缀 + 组织段 + 日期段 + 流水段”，长度固定，全部大写；编码一经生成不可修改，不可复用 |
| 名称 | 中文名称使用全角字符，英文名称使用半角；不得包含表情符号与特殊控制字符；首尾空格自动去除 |
| 日期时间 | 日期格式 YYYY-MM-DD，时间格式 YYYY-MM-DD HH:mm:ss（24 小时制）；接口传输使用 ISO 8601 带时区 |
| 金额 | 存储为定点小数，两位小数；展示带千分位与币种符号；接口传输以最小货币单位（分）的整数字符串传递，避免浮点误差 |
| 数量 | 按基本单位存储，两位小数；销售单位与基本单位换算率必须为整数，禁止出现 0.333 箱 |
| 单位 | 所有数量字段必须携带单位标识，界面展示与存储单位分离，避免“30 箱”被误读为“30 支” |
| 地址 | 按省/市/Barangay/街道四级结构化存储，另存完整地址文本用于打印；坐标保留 6 位小数 |
| 状态 | 使用固定枚举编码（英文大写），展示文案与编码分离，便于多语言与报表统计 |
| 多语言 | 名称类字段支持中英双语存储；不自动翻译用户录入内容；报表导出使用当前界面语言 |
| 附件 | 文件命名规则“业务类型\_对象编码\_序号\_时间戳”，存储路径按“业务类型/年月/业务单元”分层 |
| 空值 | 区分“空”与“零”，金额未填为 null，数量为 0 表示确实为零；报表中 null 显示为“—”，0 显示为“0” |
| 唯一性 | 主数据编码全局唯一；业务单据号在业务单元内唯一；接口幂等键全局唯一 |

## 6.3  数据质量要求

数据质量不能只靠“录入时校验”，还需要在运行中持续监控。系统需按六个维度定义质量标准，并为每个维度设定可观测的指标与阈值，超标时进入数据治理流程。

**表113  数据质量维度与阈值**

| 维度 | 要求 | 监控指标 | 阈值 |
| --- | --- | --- | --- |
| 完整性 | 必填字段不得为空；关键关联字段必须有效 | 必填字段空值率、无效外键占比 | 空值率 ≤ 2%，无效关联 = 0 |
| 唯一性 | 编码、条码、幂等键不得重复 | 重复记录数 | 0 |
| 准确性 | 坐标与地址一致、金额勾稽成立、库存账实相符 | 坐标偏差超过 200 米占比、金额勾稽失败数、盘点差异率 | 偏差占比 ≤ 1%，勾稽失败 = 0，差异率 ≤ 1% |
| 一致性 | 同一指标在不同报表中的值一致；主数据在多模块引用一致 | 跨报表差异数 | 0 |
| 及时性 | 业务发生到数据可见的延迟在可接受范围 | 订单落库延迟、报表更新延迟、离线数据上传延迟 | 订单 ≤ 5 秒，报表 ≤ 1 小时，离线 ≤ 24 小时 |
| 有效性 | 数据符合业务规则与格式约束 | 校验失败率、异常签到率、重复门店数 | 校验失败率 ≤ 1%，异常签到率 ≤ 5% |

治理机制包括三步：每日自动生成数据质量报告并推送至数据责任人；每周由经销商管理员处理本单元的异常清单，未处理项进入大区经理待办；每月由总部对各单元的数据质量评分排名，纳入经销商考核。评分规则为六维度加权，权重由事业部设定，初期建议完整性 25%、准确性 30%、及时性 20%、一致性 15%、唯一性与有效性各 5%。

说明：本节的阈值是基于行业常见水平的建议值，须在试点期采集实际数据后校准。校准前不得据此直接对经销商扣分。

<a id="section-6-4"></a>

## 6.4  数据生命周期与归档

**表114  数据生命周期**

| 数据类型 | 在线保留 | 归档保留 | 归档后处理 |
| --- | --- | --- | --- |
| 主数据 | 长期在线 | 停用后保留 5 年 | 可查询，不可编辑 |
| 订单与发货数据 | 3 年 | 5 年 | 只读查询，报表仍可汇总 |
| 收款与对账数据 | 5 年 | 10 年 | 只读，满足财务审计要求 |
| 拜访与照片 | 1 年 | 2 年 | 照片转冷存储，缩略图保留 |
| 操作与接口日志 | 2 年 | 5 年 | 只读，支持按对象检索 |
