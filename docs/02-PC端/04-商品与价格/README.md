## 3.4.1  模块概述

商品与价格模块支撑“卖什么、卖多少钱、按什么规则卖”。冰淇淋的商品结构具有明显特征：同一口味存在多种包装规格（单支、家庭装、多支装、箱），SKU 数量多而单品价值低，促销频繁且按渠道差异定价。因此商品档案必须表达规格与换算，价目表必须支持按渠道、客户等级与时间生效的多维组合。

本模块的商品、价目表由事业部统一维护，经销商在授权范围内维护终端执行价。价格一旦被订单引用即锁定，后续调价不回溯历史单据，保证账实与审计口径一致。

## 3.4.3  商品

商品以 SKU 为最小管理单元。同一口味的不同规格必须建立独立 SKU，不得通过备注区分，否则库存与销量统计必然失真。商品档案同时承载库存属性（保质期、存储条件、批次管理）、销售属性（销售单位、箱规、最低售价）与税务属性（税率、含税标志）。

**表44  商品字段说明**

| 字段 | 类型 | 必填 | 说明与校验 |
| --- | --- | --- | --- |
| SKU 编码 | 文本 | 是 | 全局唯一，≤ 20 字符，规则见附录A；创建后不可修改 |
| 商品名称 | 文本 | 是 | ≤ 60 字符，含口味与规格，如“蒙牛随变香草 80ml×24” |
| 英文名称 | 文本 | 否 | ≤ 100 字符，用于英文单据与界面 |
| 品牌 | 下拉 | 是 | 取自品牌表 |
| 商品分类 | 下拉 | 是 | 取自商品分类，决定默认税率与必铺属性 |
| 规格描述 | 文本 | 是 | 净含量与包装形式，如 80ml/支、24 支/箱 |
| 基本单位 | 下拉 | 是 | 库存与结算的基础单位，通常为“箱” |
| 销售单位 | 下拉 | 是 | 下单可选单位，支持箱与支；与基本单位存在换算关系 |
| 换算率 | 数值 | 是 | 1 销售单位 = N 基本单位；以支销售时换算率为 1/箱规 |
| 箱规 | 整数 | 是 | 每箱包含的最小销售单元数量，用于拆零与配送核算 |
| 保质期天数 | 整数 | 是 | 冰淇淋通常 180—540 天，用于效期预警计算 |
| 存储条件 | 枚举 | 是 | 冷冻（-18℃）/冷藏/常温；冰淇淋固定为冷冻 |
| 税率 | 数值 | 是 | 默认 12%，允许按品类调整 |
| 价格含税标志 | 布尔 | 是 | 决定价目表价格的含税口径，同一商品不可混用 |
| 标准成本 | 数值 | 否 | 用于毛利测算，四位小数 |
| 最低售价 | 数值 | 否 | 低于该价格的订单须审批；0 表示不限制 |
| 标准零售价 | 数值 | 否 | 指导门店售价，用于陈列价签核对 |
| 是否允许退货 | 布尔 | 是 | 冰淇淋默认允许质量原因退货，非质量原因默认不允许 |
| 是否启用批次 | 布尔 | 是 | 冰淇淋固定启用，按批次与效期管理 |
| 商品图片 | 图片 | 否 | ≤ 2MB，移动端展示用于辅助识别 |
| 条码 | 文本 | 否 | EAN-13，支持扫码下单；重复条码禁止保存 |
| 状态 | 枚举 | 是 | 在售/停售/新品待上市 |

## 3.4.4  价目表

价目表是价格的容器，一个价目表包含若干商品的价格明细，并带有适用范围与生效期间。系统在开单时按“客户专属价 &gt; 促销价 &gt; 渠道价 &gt; 标准价”的优先级取价，同一优先级内取生效日期最晚的一条；若仍冲突，取价格较低者并记录取价来源，便于事后解释。

**表46  价目表字段说明**

| 字段 | 类型 | 必填 | 说明与校验 |
| --- | --- | --- | --- |
| 价目表编码 | 文本 | 是 | 全局唯一，≤ 16 字符 |
| 价目表名称 | 文本 | 是 | 如“2026 年 Q4 传统渠道标准价” |
| 价目表类型 | 枚举 | 是 | 标准价/渠道价/促销价/客户专属价/经销商结算价 |
| 所属业务单元 | 下拉 | 是 | 经销商级价目表仅在本经销商生效 |
| 适用渠道 | 多选 | 条件 | 类型为渠道价时必填 |
| 适用客户分类 | 多选 | 条件 | 类型为客户专属价时可按分类批量适用 |
| 适用客户 | 多选 | 条件 | 类型为客户专属价时可指定单个客户 |
| 币种 | 下拉 | 是 | 默认 PHP |
| 含税标志 | 布尔 | 是 | 须与商品档案一致，不一致时禁止保存 |
| 生效开始 / 结束日期 | 日期 | 是 | 结束日期不得早于开始日期；到期后自动失效并提示续期 |
| 优先级 | 整数 | 是 | 数值越大优先级越高；同一范围同一时段不允许出现相同优先级的两张表 |
| 状态 | 枚举 | 是 | 草稿/待审核/生效/失效/停用 |
| 审批人 / 审批时间 | 自动 | 条件 | 促销价与客户专属价必填 |

**表47  价格明细字段说明**

| 价格明细字段 | 类型 | 必填 | 说明与校验 |
| --- | --- | --- | --- |
| 商品 | 下拉 | 是 | 从在售商品中选择 |
| 销售单位 | 下拉 | 是 | 箱或支，与商品档案一致 |
| 单价 | 数值 | 是 | 四位小数；低于商品最低售价时须审批 |
| 阶梯起订量 | 数值 | 否 | 达到该数量时适用本行价格，支持多档阶梯 |
| 折扣率 | 数值 | 否 | 0—100%，与单价二选一或叠加时须明确计算顺序 |
| 赠品数量 | 数值 | 否 | 买赠活动的赠品数量，按销售单位计 |
| 生效期间 | 日期区间 | 否 | 为空时继承价目表整体生效期 |

**表48  商品与价格业务规则**

| 编号 | 业务规则 |
| --- | --- |
| BR-PRD-01 | 取价优先级：客户专属价 &gt; 促销价 &gt; 渠道价 &gt; 标准价；同优先级取生效日期最晚者；仍冲突取低价并记录 |
| BR-PRD-02 | 订单保存时锁定价格快照，后续价目表变更不影响已保存订单 |
| BR-PRD-03 | 低于商品最低售价的成交须提交审批，审批人默认为经销商管理员，超过阈值升级至大区经理 |
| BR-PRD-04 | 同一商品在同一价目表中不得出现两条生效期重叠的明细，保存时校验 |
| BR-PRD-05 | 赠品必须关联主商品，赠品金额按 0 元计入订单，但单独统计赠品数量与成本 |
| BR-PRD-06 | 价目表到期前 7 天向维护人推送提醒，到期未续期自动失效，开单时回退至上一优先级价格并提示 |
| BR-PRD-07 | 经销商调整终端执行价只能在事业部授权区间内进行，超出区间的调整需事业部审批 |
