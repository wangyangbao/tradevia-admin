# 3  PC 端功能需求

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》第 3 章开篇与菜单总览。原文状态为“需求评审稿（待业务方确认）”，本文件按模块整理，未改变业务规则。

[返回文档总目录](../README.md)

本章按一级菜单顺序展开，每个模块统一按“功能概述—菜单与页面—功能点—字段—按钮与交互—业务规则”的结构描述。功能点编号（FR-）用于与测试用例、开发任务单对应，优先级 P0 表示上线必备，P1 表示首版应具备，P2 表示可延后。

**表19  PC 端菜单总览**

| 一级菜单 | 二级菜单 | 主要使用者 | 优先级 |
| --- | --- | --- | --- |
| 组织架构 | 业务单元、部门、人员 | 总部管理员、经销商管理员 | P0 |
| 基础数据 | 单位、币种、品牌、渠道 | 总部管理员、事业部 | P0 |
| 门店管理 | 门店分类、客户 | 经销商管理员、业务员、大区经理 | P0 |
| 商品管理 | 商品分类、商品、价目表 | 事业部、经销商财务 | P0 |
| 外勤管理 | 外勤动作、外勤类型、外勤规则、线路规划 | 大区经理、经销商管理员 | P0 |
| 销售管理 | 销售订单、发货单、销售出库 | 业务员、经销商财务、仓管 | P0 |
| 库存管理 | 仓库、入库单、出库单、库存查询、调拨单 | 仓管员、经销商管理员 | P0 |
| 报表管理 | 外勤拜访记录、销售报表、业务员销售业绩、业务员对账单 | 各层级管理者、财务 | P0 |
| 权限管理 | 角色、权限分配 | 总部管理员 | P0 |
| 三方系统接口 | 订单接口（含接口监控） | 总部信息化、实施顾问 | P1 |
| 操作日志 | 操作日志查询 | 总部管理员、审计 | P1 |
