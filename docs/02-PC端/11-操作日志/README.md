# 3.11  操作日志

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》第 3.11 节。原文状态为“需求评审稿（待业务方确认）”，本文件按模块整理，未改变业务规则。

[返回文档总目录](../../README.md)

操作日志用于审计与问题追溯，必须做到“谁在什么时间、用什么终端、对什么对象、做了什么、结果如何”五要素齐全。日志与业务数据分离存储，业务单据作废或被修改不影响日志记录。

**表90  操作日志字段**

| 字段 | 说明 |
| --- | --- |
| 日志编号 / 发生时间 | 服务端时间，精确到毫秒 |
| 操作人 / 所属业务单元 / 角色 | 记录操作时的组织与角色快照，人员调岗后仍可追溯当时身份 |
| 终端类型 / IP / 设备标识 | PC 记录浏览器与 IP；移动端记录设备型号、系统版本与 IMEI 哈希 |
| 模块 / 功能 / 操作类型 | 如“销售管理—销售订单—审核” |
| 对象类型 / 对象标识 | 如订单号、客户编码、商品 SKU |
| 变更前值 / 变更后值 | 仅记录发生变化的字段，敏感字段（密码、身份证号）不记录明文 |
| 执行结果 / 耗时 / 追踪号 | 成功、失败及失败原因；追踪号用于关联接口日志 |

**表91  操作日志规则**

| 编号 | 业务规则 |
| --- | --- |
| BR-LOG-01 | 日志只允许查询与导出，不提供删除与修改入口；超过保留期的日志由系统归档，归档后仍可查询 |
| BR-LOG-02 | 保留期：业务操作日志不少于 2 年，财务与收款相关日志不少于 5 年，登录日志不少于 1 年 |
| BR-LOG-03 | 导出日志本身也记录日志，形成“谁导出了什么数据”的闭环 |
| BR-LOG-04 | 登录失败、越权访问、批量删除、批量导出四类行为单独告警，连续异常时锁定账号 |
| BR-LOG-05 | 日志查询支持按操作人、时间、模块、对象标识、结果组合筛选，单次查询时间跨度不超过 90 天 |
