# 3.8  报表管理

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》第 3.8 节。原文状态为“需求评审稿（待业务方确认）”，本文件按模块整理，未改变业务规则。

[返回文档总目录](../../README.md)

<a id="section-3-8-1"></a>

## 3.8.1  模块概述

报表是管理层判断执行质量的唯一客观依据，因此报表的第一要求不是“多”，而是“口径唯一”。同一个指标在不同报表中必须由同一段计算逻辑产生，不允许各报表自行取数。系统将所有指标定义集中在指标字典中，报表只引用指标编码，从而保证“销售报表里的销额”与“业绩报表里的销额”永远相等。

**表77  报表清单**

| 报表 | 核心问题 | 主要使用者 | 更新频率 |
| --- | --- | --- | --- |
| 外勤拜访记录 | 业务员是否按计划到店、到店做了什么 | 大区经理、经销商管理员 | 实时 |
| 销售报表 | 卖了什么、卖给谁、卖了多少 | 各层级管理者、事业部 | 每小时 |
| 业务员销售业绩 | 谁完成了目标、差距在哪 | 大区经理、经销商管理员 | 每日 |
| 业务员对账单 | 收了多少钱、交了多少、差在哪 | 财务、业务员 | 每日 |

<a id="section-3-8-2"></a>

## 3.8.2  外勤拜访记录

该报表回答“拜访是否真实、是否有效”。列表以拜访记录为行，展示计划与实际的时间、位置、动作完成情况、订单结果。系统同时提供汇总视图：按业务员、按线路、按门店统计签到率、有效拜访率、平均停留时长、订单转化率。

**表78  外勤拜访记录报表明细**

| 列字段 | 说明 | 示例口径 |
| --- | --- | --- |
| 拜访日期 / 计划时间 / 实际签到时间 | 计划取线路，实际取签到记录 | 迟到超过 30 分钟标记“迟到” |
| 大区 / 经销商 / 业务员 / 线路 | 组织维度 | 按当前用户数据权限过滤 |
| 客户编码 / 名称 / 分类 | 门店维度 | 支持按分类汇总 |
| 签到距离（米） | 签到坐标与门店坐标的直线距离 | 超过规则半径标记“异常签到” |
| 停留时长（分钟） | 离店时间减签到时间 | 低于最短停留标记“疑似走过场” |
| 动作完成情况 | 签到/门头照/陈列照/铺货/订单/离店逐项打勾 | 未完成项以红色标记 |
| 订单金额 / 订单数 | 本次拜访产生的订单 | 零订单拜访单独统计 |
| 异常标记 | 异常签到、跳过动作、重复拜访、离线提交 | 多个异常以标签并列展示 |
| 照片 | 缩略图，点击查看大图与水印信息 | — |

汇总视图提供四个核心指标：签到率等于有效签到次数除以计划拜访次数；有效拜访率等于完成全部必做动作且停留达标的拜访数除以计划拜访次数；订单转化率等于产生订单的拜访数除以有效拜访数；人均日拜访数等于有效拜访数除以出勤天数。四个指标均按周、月两个周期提供趋势图。

<a id="section-3-8-3"></a>

## 3.8.3  销售报表

销售报表支持多维度自由组合：时间（日/周/月/季）、组织（大区/经销商/业务员）、商品（品牌/品类/SKU）、客户（渠道/分类/单店）、来源（访销/车销/接口）。默认展示销额、销量、订单数、客单价、退货额、净销额六项指标，并支持与上期、同期、目标值三向对比。

**表79  销售报表指标口径**

| 指标 | 定义 | 计算口径与说明 |
| --- | --- | --- |
| 销额 | 订单签收确认的含税金额 | 以签收时点计入，未签收不计；接口订单以回传确认时点计入 |
| 销量 | 签收商品折算为基本单位（箱）的数量 | 支装销售按换算率折算，保留两位小数 |
| 订单数 | 计入统计的有效订单数量 | 已取消、已驳回订单不计入 |
| 客单价 | 销额 ÷ 订单数 | 订单数为 0 时显示“—”，不显示 0 |
| 退货额 | 退货单确认的含税金额 | 单独列示，不冲减销额，另计净销额 |
| 净销额 | 销额 − 退货额 | 作为业绩达成与返利计算的基础 |
| 赠品成本 | 赠品数量 × 标准成本 | 不计入销额，单独统计用于费用分析 |
| 铺货率 | 在售必铺 SKU 的门店数 ÷ 覆盖门店数 | 按商品与区域计算，需与拜访上报数据关联 |

**表80  销售报表功能点**

| 功能编号 | 功能点 | 功能描述 | 优先级 |
| --- | --- | --- | --- |
| FR-RPT-01 | 多维交叉分析 | 最多选择四个维度进行行列交叉，支持切换指标 | P0 |
| FR-RPT-02 | 趋势与对比 | 按日/周/月展示趋势，支持同比、环比、目标对比 | P0 |
| FR-RPT-03 | 下钻 | 从大区下钻到经销商、业务员、门店、单据明细 | P0 |
| FR-RPT-04 | 导出与订阅 | 导出 Excel/PDF；支持按周/月定时推送至指定人员 | P1 |
| FR-RPT-05 | 目标录入 | 按月录入大区、经销商、业务员的销量与销额目标 | P1 |
| FR-RPT-06 | 异常提示 | 销量环比下降超过 20%、退货率超过 5% 时自动标注 | P2 |

<a id="section-3-8-4"></a>

## 3.8.4  业务员销售业绩

业绩报表面向考核，必须做到“可解释”。每个业务员的业绩行需同时展示目标、实际、达成率、排名，以及构成实际的明细（订单数、活跃门店数、新开门店数、拜访数）。当达成率低于阈值时，系统给出归因提示：是拜访量不足、转化率低，还是客单价下降。

**表81  业务员销售业绩报表明细**

| 列字段 | 说明 | 计算方式 |
| --- | --- | --- |
| 业务员 / 所属经销商 / 线路 | 考核主体 | 按人员维度汇总 |
| 月度目标（销额 / 销量） | 由目标录入维护 | 取当月生效目标，未录入时显示“未设定” |
| 实际销额 / 销量 | 签收口径 | 与销售报表同源 |
| 达成率 | 实际 ÷ 目标 | 目标为 0 时显示“—”，不计算百分比 |
| 活跃门店数 | 当月有订单的门店数 | 去重统计，含新开与存量 |
| 新开门店数 | 首次订单发生在当月的门店数 | 按首访日期与首单日期判定 |
| 拜访数 / 有效拜访数 | 来自外勤记录 | 有效拜访定义见 3.8.2 |
| 订单转化率 | 有订单的拜访数 ÷ 有效拜访数 | 反映拜访质量 |
| 排名 / 分位 | 同经销商内排名、同大区内分位 | 仅在有权限范围内计算 |
| 归因提示 | 低于 80% 达成率时给出主因 | 按拜访量、转化率、客单价三项与均值比较 |

<a id="section-3-8-5"></a>

## 3.8.5  业务员对账单

对账单是资金安全的最后一道闸门。系统按“业务员 + 日期”生成对账单，汇总当日经手的订单与收款，计算应交与实交，差异必须逐笔说明。对账单确认后，当日数据锁定，任何修改需通过冲正单据处理。

**表82  业务员对账单字段**

| 列字段 | 说明 | 计算方式 |
| --- | --- | --- |
| 对账日期 / 业务员 / 经销商 | 对账主体 | 按日生成，支持按周汇总查看 |
| 期初应收 | 上日结存的客户欠款 | 取上一对账日确认后的应收余额 |
| 本期销售（含税） | 当日签收的订单金额 | 签收口径，不含未签收订单 |
| 本期退货 | 当日确认的退货金额 | 冲减应收 |
| 本期收款：现金 / 支票 / 转账 / 电子钱包 | 按结算方式分列 | 取收款单，已核销金额为准 |
| 期末应收 | 期初 + 本期销售 − 本期退货 − 本期收款 | 结果须与客户应收明细合计一致 |
| 应交现金 | 当日现金方式收款合计 | 仅统计现金，非现金不计入应交 |
| 实交现金 | 业务员实际移交财务的金额 | 由交款单录入 |
| 差异金额 | 实交 − 应交 | 正数为多交，负数为短款 |
| 差异原因 | 枚举：找零未登记/代付/门店拒收/票据未到账/其他 | 短款必须选择原因并说明 |
| 对账状态 / 确认人 / 确认时间 | 见 2.9.5 | 财务确认后锁定 |

**表83  报表通用规则**

| 编号 | 业务规则 |
| --- | --- |
| BR-RPT-01 | 报表数据权限与业务数据权限一致，越权查询返回空结果而非报错 |
| BR-RPT-02 | 对账单生成时点为每日 23:00，未完成拜访或未登记收款的业务员次日仍可补录，但需标记“补录” |
| BR-RPT-03 | 差异金额绝对值超过 500 比索时，须大区经理确认；超过 2000 比索时须事业部财务复核 |
| BR-RPT-04 | 报表导出文件命名包含报表名、筛选条件摘要与生成时间，导出行为写入操作日志 |
| BR-RPT-05 | 所有金额类指标保留两位小数，比率类指标保留一位小数并以百分号展示 |
