# 3.12  PC 端通用交互要求

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》第 3.12 节。原文状态为“需求评审稿（待业务方确认）”，本文件按模块整理，未改变业务规则。

[返回文档总目录](../../README.md)

本节规定所有列表页、表单页、详情页的共性规则。若不统一，会出现同一系统内不同页面交互逻辑不一致的问题，直接增加培训成本。

**表92  PC 端通用交互规范**

| 场景 | 统一要求 |
| --- | --- |
| 列表页 | 顶部筛选区不超过两行，超出部分折叠为“更多条件”；列可配置显示与顺序；默认每页 20 条，可切换 50/100；空数据展示插图与引导文案，不显示“暂无数据”四个字了事 |
| 查询 | 查询按钮触发查询，重置按钮清空全部条件；输入框支持回车查询；日期区间默认本月；跨年查询需显式选择 |
| 表单 | 必填项以红色星号标记；校验失败时定位到第一个错误字段并高亮；离开未保存页面时二次确认 |
| 保存 | 保存成功后提示并刷新列表，停留在当前页；保存失败保留已填内容，不清空表单 |
| 删除 / 作废 | 二次确认弹窗须说明后果（如“作废后库存将释放，不可恢复”），危险按钮使用红色 |
| 状态展示 | 状态标签颜色固定：草稿灰、进行中蓝、成功绿、失败红、超期橙；同状态在全系统颜色一致 |
| 分页与批量 | 批量操作前显示已选条数；跨页选择需明确提示；批量操作结果以汇总方式反馈成功与失败数量 |
| 导出 | 导出前提示数据量与预计耗时；超过 5000 行时改为异步导出并站内通知下载 |
| 权限不足 | 无权限的菜单不显示；无权限的按钮置灰并提示“无权限，请联系管理员”，不弹出空白页 |
| 加载与超时 | 超过 3 秒的操作用进度提示；超时后给出重试按钮，不静默失败 |

## 2026-11-10 外勤管理交互

外勤管理采用统一紧凑页头、筛选区、单行汇总、固定表头、分页和 CSV 导出。配置详情、拜访详情使用右侧抽屉，关闭后保留列表筛选与分页。编辑使用弹窗，报错保留输入；停用和删除须填写原因，并检查引用；历史拜访快照不随配置修改而变化。规则试算改变输入时清除旧结果。统计可按人员或门店下钻记录。六个菜单归入外勤管理，原 `#visitRoutes` 地址保持可用。页面模拟交互已验证；真实浏览器视觉验收受当前浏览器设置限制。具体范围见[外勤一期实现与验收](../05-外勤管理/一期实现与验收.md)。

## 2026-11-11 销售页面交互

四个销售菜单采用紧凑页头、查询/重置、分页、数量及金额汇总，订单支持当前页选择和管理员批量审核结果反馈。新建先选择访销/车销，再进入完整页面；订单、发货、出库确认、发票采用全页编辑。未保存取消和菜单跳转需确认，报错保留输入；浏览器关闭使用原生提示。详情继续使用右侧抽屉，关联订单、发货、出库与发票在抽屉原位切换，关闭保留列表条件。作废须原因与确认，已出库记录保持锁定。导出前确认当前查询条数，A4 打印由浏览器处理。页面交互已用模拟环境验证；实际浏览器视觉、打印和下载仍待复核。详见[销售一期实现与验收](../06-销售管理/一期实现与验收.md)。
