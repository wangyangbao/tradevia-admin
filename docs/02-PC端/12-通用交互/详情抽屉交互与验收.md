# 详情抽屉交互与验收

## 交互选择

单据通常有多组字段、商品明细与关联记录，采用右侧宽抽屉更适合连续查阅。打开详情时保留原列表、筛选与滚动位置；左侧列表作为参照。小弹窗继续用于删除等简短确认，新建和编辑继续使用原有表单。

参考图只作为布局参考。摘要指标、页签与操作均以现有功能和数据为准，不添加尚未实现的退款、开票、物流或审批操作。

## 已接入范围

- 销售订单：列表、工作台与搜索打开同一套详情；客户档案的销售订单复用同一布局。
- 客户收款单：查看收款信息，点击关联订单可在同一个抽屉内切换；订单的关联收款也可直接查看。
- 收款与对账：应收单号新增详情入口，展示现有应收金额、已收金额、余额和基本信息。
- 商品：顶部展示图片、状态及标准零售价，下方分基本信息、单位包装、价格税率、库存质量，以及价目表明细页签。
- 价目表：顶部展示状态、业务单元、适用范围、币种和有效期，下方展示商品价格、适用客户与审核信息；保留维护权限。
- 经销商等列表已有的简短详情统一使用抽屉。
- 客户档案：保留列表作为背景，档案从右侧展开；支持上一位、下一位客户、放大还原及 Esc 关闭。编辑与状态变更在抽屉上方打开。
- 客户档案中的订单和收款复用当前抽屉，提供“返回客户档案”；Esc 先返回客户档案，再关闭抽屉。返回时保留档案页签、查询条件、滚动位置和原单据入口焦点。

## 布局与操作

- 桌面端从右侧滑出，保留工作台顶部和左侧部分列表；浅色遮罩，背景列表暂不可操作。
- 顶部编号或名称、类型、操作和关闭按钮固定；详情正文独立滚动。
- 支持放大至整个视口、还原宽度、Esc 及点击遮罩关闭。
- 关闭后尝试恢复到原入口的键盘焦点，不滚动原页面；关联记录切换不叠加多个抽屉。
- 小屏宽度不超过 800px 时自动占满屏幕，宽表格在正文区域内横向滚动。
- 页签支持左右方向键、Home、End，按钮和页签保留键盘焦点提示。

## 数据口径

金额及价格使用原有存储单位和格式化规则。订单摘要仅在存在客户台账时展示已确认回款和待收余额，只有已签收订单形成应收；仅同客户、同订单的已确认收款计入回款。旧样例订单不推算收款。历史价格显示订单原快照，不重新取价。

## 验证

自动检查包括类型与构建检查、代码检查、既有功能回归，以及详情渲染验证：收款状态、客户和订单关联、未形成应收、旧样例单据、四位价格与税率快照。

补充了模拟页面环境下的交互检查，验证基础档案分类原位切换、只读权限、客户列表保留、筛选和滚动位置、关闭后焦点恢复、前后客户切换、编辑窗口层级，以及关联单据返回。这些检查不启动浏览器，不替代真实浏览器的视觉验收。

基础档案目录内的“商品分类”“门店分类”在当前档案工作区切换，不改变系统菜单和网址。商品分类复用商品管理的分类树及维护规则，门店分类复用原有档案数据；切换后目录继续保留。

当前 Work 设置关闭了本地浏览器操作，未完成真实浏览器点击和截图验收。建议在预览中重点确认：长详情的独立滚动、放大还原、Esc、遮罩关闭、焦点返回、关联单据切换、商品与价目表转编辑，以及窄屏表格滚动。
