# 3.7  库存管理

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》第 3.7 节。原文状态为“需求评审稿（待业务方确认）”，本文件按模块整理，未改变业务规则。

[返回文档总目录](../../README.md)

<a id="section-3-7-1"></a>

## 3.7.1  模块概述

库存管理覆盖仓库、入库单、出库单、库存查询、调拨单五个菜单。其核心约束只有一条：库存数量只能由已审核或已执行的单据改变，系统不提供任何形式的“直接修改库存”入口。这条约束保证了任何一笔账面差异都能追溯到具体单据与责任人。

冰淇淋的库存管理有三个特殊要求。第一，必须按批次与效期管理，出库遵循先进先出，临期批次可配置禁售。第二，必须支持车仓这一移动虚拟仓，车销商品在装车后即从实体仓转入车仓，日终回仓。第三，必须支持拆零，销售按支、库存按箱，换算关系必须在每一次库存变动时保持精确。

<a id="section-3-7-2"></a>

## 3.7.2  仓库

仓库分为四类：经销商中心仓（实体仓，存放全部品类）、前置仓（区域分仓，用于缩短配送半径）、车仓（虚拟仓，挂在车辆上）、退货仓（隔离存放待处理的退货商品）。仓库类型决定其可参与的单据类型，例如车仓只能参与调拨与车销出库，不能参与采购入库。

**表69  仓库字段说明**

| 字段 | 类型 | 必填 | 说明与校验 |
| --- | --- | --- | --- |
| 仓库编码 | 文本 | 是 | 全局唯一，规则 WH-{经销商}-{3 位} |
| 仓库名称 | 文本 | 是 | ≤ 40 字符 |
| 仓库类型 | 枚举 | 是 | 中心仓/前置仓/车仓/退货仓；类型决定可参与的单据 |
| 所属经销商 | 下拉 | 是 | 仓库不可跨经销商使用 |
| 仓库地址 / 坐标 | 文本 + 坐标 | 条件 | 实体仓必填，车仓可不填 |
| 绑定车辆 | 下拉 | 条件 | 车仓必填，用于关联车销业务员 |
| 库容量（箱） | 数值 | 否 | 用于容量预警，达到 90% 时提示 |
| 负责人 | 人员选择 | 是 | 仓管员或经销商管理员 |
| 是否允许负库存 | 布尔 | 是 | 默认否；仅退货仓可开启，用于先收货后质检场景 |
| 状态 | 枚举 | 是 | 启用/停用 |

<a id="section-3-7-3"></a>

## 3.7.3  入库单

入库单承接四类来源：采购到货、调拨入库、销售退货入库、盘盈入库。不同来源的字段与校验略有差异，但统一采用“先建单、后审核、再入库”的三步流程（采购到货可配置为免审直接入库）。入库时必须录入批次与生产日期，系统据保质期自动计算效期，效期为空时禁止入库。

**表70  入库单字段说明**

| 字段 | 类型 | 必填 | 说明与校验 |
| --- | --- | --- | --- |
| 入库单号 | 文本 | 自动 | 规则 IB-{仓库}-{YYYYMMDD}-{4 位} |
| 入库类型 | 枚举 | 是 | 采购到货/调拨入库/退货入库/盘盈入库/其他 |
| 来源单号 | 关联 | 条件 | 调拨与退货必填，采购可填采购订单号 |
| 仓库 | 下拉 | 是 | 车仓不可用于采购到货 |
| 供应商 / 来源方 | 下拉 | 条件 | 采购到货必填 |
| 明细：商品 / 批次 / 生产日期 / 效期 | 子表 | 是 | 批次唯一，效期由生产日期加保质期自动计算 |
| 数量 | 数值 | 是 | 大于 0；按基本单位计 |
| 到货温度（可选） | 数值 | 否 | 冷链到货记录，低于 -15℃ 时提示复核 |
| 经办人 / 入库时间 | 人员 + 时间 | 是 | 确认入库时写入 |
| 单据状态 | 枚举 | 自动 | 草稿/待审核/已审核/已入库/已作废 |

**表71  入库业务规则**

| 编号 | 业务规则 |
| --- | --- |
| BR-IB-01 | 同一仓库同一批次重复入库时，合并到已有批次记录，不新建批次号 |
| BR-IB-02 | 效期早于当前日期的商品禁止入库；效期不足 30 天的商品入库时标记“临期”，单独存放 |
| BR-IB-03 | 采购到货数量与采购订单差异超过 5% 时须填写差异说明，并通知采购方 |
| BR-IB-04 | 入库确认后生成库存台账记录，记录批次、数量、单价与来源单据 |

<a id="section-3-7-4"></a>

## 3.7.4  出库单

出库单在销售场景下由发货单驱动，在非销售场景（调拨、报损、领用）下可手工创建。为避免重复，系统对同一发货单只允许生成一张销售出库单；确需分批出库时，按“拆分发货单”处理，而不是多次出库同一张单。

**表72  出库单字段说明**

| 字段 | 类型 | 必填 | 说明与校验 |
| --- | --- | --- | --- |
| 出库单号 | 文本 | 自动 | 规则 OB-{仓库}-{YYYYMMDD}-{4 位} |
| 出库类型 | 枚举 | 是 | 销售出库/调拨出库/报损出库/领用出库/其他 |
| 仓库 / 关联单据 | 下拉 + 关联 | 是 | 销售出库必填发货单；调拨出库必填调拨单 |
| 明细：商品 / 批次 / 效期 / 数量 | 子表 | 是 | 批次须在库存中可用，效期不足预警阈值时提示 |
| 出库原因 | 枚举 | 条件 | 报损须选择：融化/破损/过期/赠品损耗/其他 |
| 经办人 / 出库时间 | 人员 + 时间 | 是 | 确认出库时写入，作为库存扣减依据 |
| 单据状态 | 枚举 | 自动 | 草稿/待审核/已审核/已出库/已作废 |

<a id="section-3-7-5"></a>

## 3.7.5  库存查询

库存查询是使用频率最高的页面之一，需同时满足“快”与“准”。系统提供按仓库、商品、批次、效期区间、库存状态（正常/临期/禁售）的多维筛选，默认按商品汇总展示，点击商品可下钻到批次明细。查询结果必须区分四个数量口径，避免管理者把“账面数”当作“可卖数”。

**表73  库存数量口径定义**

| 数量口径 | 定义 | 计算方式 | 用途 |
| --- | --- | --- | --- |
| 账面数量 | 仓库中实际记录的数量 | 期初 + 入库 − 出库 ± 调整 | 盘点对账的基准 |
| 锁定量 | 已被订单占用但尚未出库的数量 | 已审核未出库订单的折箱数量之和 | 防止超卖 |
| 可用数量 | 当前可以承诺给客户的数量 | 账面数量 − 锁定量 | 开单时的校验依据 |
| 在途数量 | 调拨已发出但目标仓未入库的数量 | 已审核未入库调拨单数量 | 避免重复调拨与重复计算 |

**表74  库存查询功能点**

| 功能编号 | 功能点 | 功能描述 | 优先级 |
| --- | --- | --- | --- |
| FR-INV-01 | 库存汇总查询 | 按商品维度展示账面、锁定、可用数量与金额 | P0 |
| FR-INV-02 | 批次明细下钻 | 展示每个批次的效期、数量、库龄与状态 | P0 |
| FR-INV-03 | 效期预警 | 按剩余保质期比例分级预警（30%/15%/7 天） | P0 |
| FR-INV-04 | 库存台账 | 按时间段查询每一笔出入库流水，可追溯到单据 | P0 |
| FR-INV-05 | 库存冻结 / 解冻 | 对问题批次冻结，冻结后不可出库，需填写原因 | P1 |
| FR-INV-06 | 库存周转分析 | 按商品计算周转天数与呆滞库存金额 | P1 |
| FR-INV-07 | 库存导出 | 导出当前筛选结果为 Excel，记录导出日志 | P1 |

<a id="section-3-7-6"></a>

## 3.7.6  调拨单

调拨连接两个仓库，最常见的场景是中心仓到车仓的装车、车仓回收余货、以及中心仓到前置仓的补货。调拨单在审核后进入“在途”，源仓扣减、目标仓未增加，此阶段库存查询必须体现为在途量，否则会出现“商品凭空消失”的错觉。

**表75  调拨单字段说明**

| 字段 | 类型 | 必填 | 说明与校验 |
| --- | --- | --- | --- |
| 调拨单号 | 文本 | 自动 | 规则 TR-{调出仓}-{YYYYMMDD}-{4 位} |
| 调拨类型 | 枚举 | 是 | 仓间调拨/装车调拨/回仓调拨/退仓调拨 |
| 调出仓库 / 调入仓库 | 下拉 | 是 | 两者不可相同；调入为车仓时须绑定车辆 |
| 关联车辆 / 司机 | 下拉 | 条件 | 装车与回仓调拨必填 |
| 明细：商品 / 批次 / 数量 | 子表 | 是 | 数量不得超过调出仓可用量 |
| 预计到达时间 | 时间 | 否 | 用于在途超期提醒，超过 24 小时未入库时告警 |
| 经办人 / 审核人 | 人员 | 是 | 审核人与经办人不得为同一人（可由管理员配置豁免） |
| 单据状态 | 枚举 | 自动 | 草稿/待审核/已审核/在途/已入库/已作废 |

**表76  调拨业务规则**

| 编号 | 业务规则 |
| --- | --- |
| BR-TR-01 | 调拨数量受调出仓可用量限制，不允许负库存调拨 |
| BR-TR-02 | 装车调拨与车销线路绑定，未装车的车辆不允许开始车销开单 |
| BR-TR-03 | 回仓调拨数量可小于装车数量，差额在车仓盘点时形成盘亏，须登记损耗原因 |
| BR-TR-04 | 在途超过 24 小时未确认入库，系统向调出仓负责人与经销商管理员推送告警 |
| BR-TR-05 | 已入库的调拨单不可撤销，差异通过反向调拨或盘盈盘亏处理 |

现有库存菜单改为销售库存台账，按商品/仓库/批次显示期初、销售出库、退货入库、实存、占用和可用量。审核占用、出库扣减，拒收与后续退货按实际回仓及处理方式回补原有效批次或报损。过期、禁售批次不可出库。仓库商品占用是汇总值，不能按批次重复相加。当前期初为演示库存，未接入采购、车仓调拨和正式盘点；不把原 PRD 的全部库存功能视为已完成。实现、核对口径和验证边界见[销售一期实现与验收](../06-销售管理/一期实现与验收.md)。
