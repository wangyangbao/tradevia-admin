# 哈尼冰淇淋项目需求文档

本目录将原始 PRD 按模块拆分，每个业务模块独立一个文件夹，便于需求评审、开发拆解和后续维护。

> 来源：《蒙牛菲律宾冰淇淋经销商运营系统 PRD V1.0》，编制日期 2026 年 11 月 6 日，状态为需求评审稿（待业务方确认）。本项目当前展示企业名称为“哈尼冰淇淋”；拆分正文保留原文中的“蒙牛”等名称，未擅自改写原始需求。

## 阅读方式

先阅读[项目说明与引言](00-项目说明/README.md)及[系统总体要求](01-系统总体要求/README.md)，再进入具体模块。全局业务规则和单据状态是各模块共同依赖；PC 端与移动端描述同一流程时，应对照阅读。

各模块保留原章节号、功能点编号、字段表、业务规则、状态值及原图。本文档描述需求范围，不表示对应功能已经实现；当前前端演示能力以[项目说明](../README.zh-CN.md)为准。

## 文档维护约定

每次功能开发、交互调整、业务规则变更或问题修复，都在同一次交付中同步更新对应模块文档，记录变化、实现范围、验证结果及已知限制。跨模块调整同时维护相关模块与通用交互说明；新增重要实现记录时更新本页索引。交付时简要说明已更新的文档。此约定同步记录于项目根目录的 [AGENTS.md](../AGENTS.md)。
