# 哈尼冰淇淋后台管理系统

哈尼冰淇淋后台是一个基于 React、TypeScript 和 Vite 的经销商运营后台演示，支持经营概览、订单、客户、库存、收款、拜访路线与中英文主题切换。

现已支持登录、注册、退出与本地演示账号。打开项目会先进入登录页面，也可一键体验演示后台；正式认证与权限服务尚未接入。

## 需求文档

[按模块查看 PRD](docs/README.md)：PC 端与移动端按模块独立建文件夹，并保留总体要求、数据规范、验收标准及原始文档。


## 组织架构（2026-11-09）

已新增业务单元、部门和人员管理，支持租户切换和本级及下级组织的数据范围。总部、事业部、大区和经销商初始演示账号见[中文项目说明](README.zh-CN.md)。当前仍为浏览器本地演示，正式服务端认证与权限尚未接入。各模块当前范围请查看[文档总目录](docs/README.md)。


## 商品管理（2026-11-10）

左侧新增「商品管理 → 商品分类、商品、价目表」。分类支持两级树；商品支持独立 SKU、单位箱规、条码、图片、上下架和 CSV 整批导入；价目表支持适用客户、批量选品、改价/折扣、阶梯价、赠品、有效期和本地审核。现有新建订单按客户匹配 PHP 价格并锁定价格来源快照。

可从 `http://127.0.0.1:5173/#productCategories` 开始体验。数据保存在当前浏览器，尚未连接真实审批和后端；销售库存联动以销售模块最新实现记录为准。详见[商品管理实现与验收](docs/02-PC端/04-商品与价格/演示实现与验收.md)。
