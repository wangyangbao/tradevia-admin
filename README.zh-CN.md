# 哈尼冰淇淋后台管理演示

基于 React、TypeScript、Vite、Tailwind CSS 和 shadcn/ui 的经销商运营后台。用于讨论信息架构和界面方向，尚未连接后端或数据库。

## 启动预览

在 macOS 中双击项目内的 `Start Tradevia.command`，保持打开的终端窗口运行。若预览已经在运行，可直接打开本地地址 `http://127.0.0.1:5173`。

也可以在项目目录运行：

```sh
npm install
npm run dev
```

建议使用 Node.js 22.12 或更新版本。项目使用固定端口 5173；如果该端口被其他程序占用，启动时会明确报错。

## 可以体验的功能

- 登录、注册、退出登录及未登录访问拦截；支持姓名、邮箱、密码、确认密码校验和密码显示切换。
- 可注册当前浏览器内有效的本地演示账号，或一键体验演示；登录默认在当前标签页保留 8 小时，可勾选保持登录 7 天。

- 八个页面：经营概览、销售订单、客户门店、拜访路线、经销商、库存管理、收款与对账、外观设置。
- 中英文即时切换，覆盖导航、标题、表格、状态、弹窗和提示。
- 五种主题色：翡翠绿、海洋蓝、鸢尾紫、琥珀橙、玫瑰红。
- 浅色、深色与跟随系统三种显示模式。
- 语言及外观偏好自动保存到当前浏览器。
- 区域筛选、列表搜索、订单及收款状态筛选、空结果提示。
- 查看订单、门店和经销商详情。
- 临时创建一笔演示订单，并查看更新后的订单列表。
- 按当前列表筛选条件导出 CSV，中文列名可正常显示。
- 快速搜索、通知入口及手机窄屏导航。
- 拜访路线支持新建、编辑、详情、启用、暂停、删除及撤销删除；可按大区、执行人、周期、状态和关键词筛选并导出。
- 路线可设置执行人与负责人、外勤类型、每周多日或每月多日拜访，以及共享或独占的客户分配规则。
- 地图分配门店：列表与真实可缩放底图联动选择，支持客户归属人、分配状态、门店类型、关键词筛选，定位门店、批量选择、移除及保存。
- 独占分配会先列出将从其他路线移出的门店，确认后统一更新；共享路线无法直接抢占其他独占路线中的门店。
- 路线配置和门店分配保存在当前浏览器，刷新和切换业务页面后仍然保留。

右上角的语言按钮切换中英文；调色板按钮快速切换主题。左侧“外观设置”提供完整偏好设置。

## 演示边界

所有门店、经销商、人员及交易均为样例，不代表真实客户业务数据。经营概览的汇总和图表为独立示例，不根据临时新建订单重算。收款、库存和订单页面用于展示，不执行真实审批、发货、支付或财务处理。

语言、主题色、显示模式，以及拜访路线和门店分配会保存在 localStorage。路线存储键为 `tradevia-visit-routes-v1`，存储不可用时会提示当前修改仅在页面会话中有效。新增演示订单只存在于当前页面会话中，刷新后恢复初始数据。登录注册为本地演示：账号及带独立随机盐的 PBKDF2 密码摘要保存在此浏览器，密码不以明文保存；所有账号共用同一份示例业务数据，不提供数据隔离。未连接正式认证、服务端权限、API、数据库、邮箱验证、找回密码或实际支付渠道。请勿使用真实业务密码。清除此网站数据会删除本地账号。

拜访路线目前覆盖规划和分配，不自动生成拜访任务，不执行签到、轨迹采集、导航或路径优化。负责人和执行人分别维护，门店在路线之间转移不会改变客户归属。独占规则适用于当前演示工作空间内的所有路线（含暂停路线）；暂停路线仍保留门店关联，已分配统计也包含暂停路线。只允许分配路线所属大区内的合作中门店；已有门店时，执行人仅可调整为同大区人员。每月不存在的日期跳过、不顺延。

地图使用 Leaflet 与 CARTO / OpenStreetMap 在线底图，不需要 API Key，加载底图需要网络。底图不可用时仍能通过列表和标记选择门店。所有门店坐标均为演示位置，不代表真实门店的精确位置。客户列表与已有门店模块共用同一份样例档案。

## 项目结构

```text
src/
  components/
    ui/                     shadcn/ui 组件
    auth-page.tsx           登录、注册与演示入口
    workspace-shell.tsx     侧边导航和顶部工具栏
    dashboard.tsx           经营概览
    records.tsx             业务列表和详情
    visit-routes-page.tsx   拜访路线、配置、门店分配和冲突确认
    visit-route-map.tsx     地图底图与门店标记
    settings-page.tsx       外观偏好
  lib/
    auth.ts                 本地演示账号、密码校验及会话
    auth-context.tsx        登录状态及退出逻辑
    auth-i18n.ts            账号页面中英文文案
    i18n.ts                 中英文文案
    preferences.tsx         语言、主题与保存逻辑
    data.ts                 演示业务数据
    visit-routes.ts         路线数据、保存校验和独占分配规则
    visit-route-i18n.ts     拜访路线中英文文案
  styles/auth.css           登录注册布局与响应式样式
  styles/workspace.css      布局、主题与响应式样式
  styles/visit-routes.css    拜访路线与地图响应式样式
  App.tsx                   页面切换和演示订单
```

## 检查与构建

```sh
npm run lint
npm test
npm run build
```

构建后的静态页面在 `dist/` 中。可运行 `npm run preview -- --host 127.0.0.1` 进行本地预览。

桌面 `Tradevia/App` 是此项目的快捷入口；实际项目保存在本次工作区的 `outputs/tradevia-admin` 中。开发和文件修改指向同一份项目。
